# Sanskrit Path

A private, local-first Sanskrit learning app inspired by the short-lesson mechanics used by modern language-learning apps.

## What works now

- Progressive lesson path with locked/unlocked lessons
- Devanagari beginner content
- Multiple-choice and typed-answer exercises
- Immediate answer feedback
- XP, hearts and streaks
- Browser-based Sanskrit pronunciation helper
- Progress saved locally in the browser with `localStorage`
- Responsive desktop/mobile layout

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Course direction

The starter course currently moves through:

1. Devanagari basics
2. People and things
3. Common actions
4. Nominative case
5. Accusative case
6. Everyday Sanskrit

The app is intentionally local-first. No account, analytics, cloud database or deployment is required to learn and keep progress on one browser.

## Content note

This project reproduces general language-learning mechanics, not Duolingo branding, artwork, proprietary course text, source code or other protected assets.
